⚠️ Akses Kamera Memerlukan HTTPS Browser memblokir kamera jika file HTML dibuka langsung dari komputer (file://). Setelah diunggah ke GitHub Pages, aplikasi ini akan berjalan secara otomatis dengan HTTPS sehingga kamera langsung dapat diakses di HP maupun laptop.
